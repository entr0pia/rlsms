# RLSMS

RLSMS is a clean, modern, and open-source replacement to the [stock messaging app](https://github.com/android/platform_packages_apps_mms) on Android, forked and modernized from [QKSMS](https://github.com/moezbhatti/qksms).

Download the latest APK from the [GitHub Releases](https://github.com/entr0pia/rlsms/releases/latest).

## Reporting bugs

A great bug report contains a description of the problem and steps to reproduce the problem. We need to know what we're looking for and where to look for it.

When reporting a bug on [GitHub Issues](https://github.com/entr0pia/rlsms/issues), please make sure to provide the following information:
- Steps to reproduce the issue
- RLSMS version
- Device / OS information
